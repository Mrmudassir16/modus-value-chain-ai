Layered Design System
1. Frontend Client Modular layout utilizing custom CSS variables for dark/light themes, rendering responsive charts via Chart.js, and integrating live RAG messaging logs.
2. Business Service Layer Encapsulates priority score calculations (weighted AP, BI, ROI, CX, Risk metrics), confidence engine parameters, and caching translators.
3. Vector Database (ChromaDB) Computes local sentence embeddings via all-MiniLM-L6-v2 SentenceTransformer, bypassing external CDNs. Retrieves matching segments with cosine proximity scores.
4. Relational Database (SQLite) Persists structured metadata, sequence lists, and conversation histories. Linked via Cascading Foreign Keys.
